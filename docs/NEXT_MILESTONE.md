# Next Milestone: Substitution, Media, and Workout Feedback

## 1. Exercise substitution

Connect a **Replace** action to each preview and active-workout exercise.

The replacement must preserve:

- Station purpose
- Primary movement role
- Requested emphasis
- Hard exclusions
- Available equipment
- Approximate technical difficulty
- Approximate repetition duration

## 2. Original demonstration media

Add an initial reviewed media set for foundational exercises:

- Goblet squat
- Romanian deadlift
- Forward and reverse lunge
- Push-up
- Dumbbell row
- Overhead press
- Pallof press
- Calf raise
- BOSU balance exercises

Use looping, silent MP4 files with thumbnails. Written instructions remain the fallback.

## 3. Post-workout feedback

Collect:

- Overall workout rating
- Too easy, appropriate, or too hard
- Exercise likes and dislikes
- Optional notes
- Whether to save the session as a favorite

Use this feedback in generator candidate scoring.

## 4. Favorites remix

Add:

- Repeat exactly
- Remix favorite
- Rename favorite
- Favorite notes and tags

## 5. Exercise library screen

Add browsing and search by:

- Body region
- Movement pattern
- Equipment
- Bodyweight versus equipment
- Familiarity
- Favorite or hidden exercise

## 6. Timer reliability

Add:

- Audio cues
- Background-state handling
- App interruption recovery
- Persisted active-session state
- Accurate resume after screen lock or brief navigation interruption
