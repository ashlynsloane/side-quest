# Side Quest V18.10 — Retro-Minimal Brand System

V18.10 applies the selected retro-minimal direction to the shared mobile UI
without changing navigation, data, or workout behavior.

## Shared visual system

- Slim navy Side Quest masthead with the approved brandmark.
- Warm cream canvas with deep navy typography and outlines.
- Forest feature cards with mint underline accents.
- A restrained stitched border on primary forest hero cards only.
- Monospaced uppercase micro-labels, badges, pills, and section headings.
- Consistent two-letter training-log marks in place of mixed emoji glyphs.
- Flatter cards with smaller shadows and stronger outlines.
- Unified bottom-tab tiles with an explicit active state.

## Scope boundaries

The update does not change routes, database schemas, integrations, planning
rules, workout generation, privacy controls, or cloud behavior. Existing
alternate themes remain available. The default Forest theme is renamed
Side Quest Classic and carries the new brand palette.

No native dependency or cloud deployment is required.
