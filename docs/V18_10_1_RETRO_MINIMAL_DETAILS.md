# Side Quest V18.10.1 — Retro-Minimal Details

This visual correction keeps the V18.10 retro-minimal system and brings the
implemented home screen closer to the approved mockup.

## Changes

- Replaces the stacked masthead artwork with a true one-line embroidered
  **Side Quest** wordmark and mint underline.
- Replaces generated two-letter action-card monograms with recognizable,
  code-native line drawings.
- Uses a checklist/clipboard for recommendations and training history.
- Uses a simple smiley for readiness and feeling check-ins.
- Adds small chart and calendar drawings where they clarify common cards.
- Keeps the original supplied symbol for cards without a dedicated drawing.
- Adds the off-white mountain, trail-sign, and winding-road illustration to
  goal-plan hero cards.

## Scope

This is a visual-only correction. Navigation, training logic, account data,
cloud integrations, native dependencies, and privacy behavior are unchanged.
No Supabase deployment or native development-client rebuild is required.
