# Side Quest V18.10.2 — Icon and Navigation Cleanup

This visual correction removes the duplicated Beta Feedback destination and
improves the legibility of the retro-minimal action-card icons.

## Changes

- Keeps Beta Feedback in **Profile → Privacy and beta**.
- Removes the duplicate Beta Feedback card from Progress.
- Enlarges all circular action-card icon containers and their artwork.
- Strengthens line weight and spacing for checklist, smiley, chart, and
  calendar drawings.
- Adds dedicated lock, sharing, and feedback-bubble drawings.
- Keeps short text marks such as PT compact while allowing ordinary symbols to
  use the larger icon scale.

## Scope

This is a visual and navigation cleanup only. Routes, training logic, stored
data, cloud integrations, and native dependencies are unchanged.
