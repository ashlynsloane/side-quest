# Side Quest V18.8 — Guided Onboarding and Beta Launchpad

V18.8 adds a first-run guide for new profiles and a reusable Setup Guide for existing athletes.

## Core principles

Entry requires acknowledgment of two product boundaries:

1. Swim, bike, and run provide planning and fatigue context but do not replace direct exercise-specific strength.
2. Coach access is limited to sanitized future strength sessions. History, pain, readiness, heart rate, Strava details, private notes, and completed loads remain private.

Most training changes remain proposals. Limited high-confidence guardrails may move, but never delete, a strength session after an extreme load when a safer date exists and an undo record can be retained.

## Setup checklist

The guide reports live status for:

- goal and training phase;
- equipment-location review;
- PT and restriction review;
- Training Intelligence review;
- optional TrainingPeaks/ICS or Strava connection;
- optional first completed Side Quest workout.

Only the two core acknowledgments block first entry. The other tasks can be completed later from Profile → Setup Guide.

## Existing profiles

Profiles with an existing goal, completed workout, calendar source, or PT profile are not forced through first-run onboarding. They can open the guide manually and review the new product boundaries.

## Storage

Onboarding status is scoped to the active Side Quest profile and stored locally. It contains acknowledgments and setup-review flags only; it does not copy training, health, or connection data.
